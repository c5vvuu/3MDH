# 🚀 دليل النشر والتشغيل الكامل على استضافة Namecheap cPanel
## Digitex Store - متجر المنتجات والخدمات الرقمية والاشتراكات

تهانينا! هذا الدليل مفصّل خطوة بخطوة لنقل ونشر وتشغيل المتجر على استضافتك الحقيقية من Namecheap دون الحاجة لأي خادم VPS أو تشغيل دائم لـ Node.js، حيث تم بناء الباك إند بالكامل بواسطة **PHP 8.2+** وقاعدة بيانات **MySQL**.

### 1. متطلبات الاستضافة
- استضافة مشتركة (Shared Hosting مثل Stellar أو Stellar Plus من Namecheap).
- إصدار PHP: يُفضّل **8.1 أو 8.2 أو 8.3** (يتم اختياره من cPanel عبر **Select PHP Version**).
- الامتدادات المطلوبة (مفعّلة افتراضياً): `pdo_mysql`, `openssl`, `mbstring`, `curl`, `json`.

---

### 2. تجهيز الدومين وشهادة SSL
1. تأكد من توجيه الـ Nameservers الخاصة بالدومين إلى استضافة Namecheap (`dns1.namecheaphosting.com` و `dns2.namecheaphosting.com`).
2. ادخل إلى **cPanel** ← ابحث عن أداة **Namecheap SSL** أو **SSL/TLS Status**.
3. اضغط **Run AutoSSL** لتفعيل شهادة الـ SSL المجانية (https) للدومين فوراً.

---

### 3. إنشاء قاعدة بيانات MySQL
1. في cPanel، افتح **MySQL® Database Wizard** (معالج قواعد البيانات).
2. **الخطوة 1**: أدخل اسم قاعدة البيانات (مثلاً: `digitex_db`). اضغط *Next Step*.
3. **الخطوة 2**: أنشئ اسم مستخدم (مثلاً: `digitex_user`) وكلمة مرور قوية واحتفظ بها. اضغط *Create User*.
4. **الخطوة 3**: ضع علامة صح على **ALL PRIVILEGES** (جميع الصلاحيات). اضغط *Make Changes*.
5. الآن لديك:
   - **Database Name**: `yourcpaneluser_digitex_db`
   - **Database User**: `yourcpaneluser_digitex_user`
   - **Password**: `YourStrongPassword`
   - **Host**: `localhost`

---

### 4. رفع ملفات المشروع
1. في cPanel، افتح **File Manager** (مدير الملفات).
2. انتقل إلى مجلد **`public_html`** (أو مجلد الدومين الفرعي إذا كان Subdomain).
3. اضغط على **Upload** وارفع ملفات المشروع:
   - ضع محتويات مجلد `public_html/` داخل الـ `public_html` على الاستضافة (يشمل `index.html`, `index.php`, `.htaccess`, ومجلد `api/`, ومجلد `install/`).
   - ارفع مجلد `app/` ومجلد `database/` إما في المجلد الرئيسي لحسابك (خارج public_html لزيادة الأمان) أو بجوار الملفات.
4. تأكد من وجود ملف `.htaccess` (قد تحتاج لتفعيل إظهار الملفات المخفية *Show Hidden Files* من إعدادات File Manager في الزاوية العلوية).

---

### 5. التثبيت التلقائي عبر معالج /install
1. افتح متصفحك واكتب رابط موقعك متبوعاً بـ `/install`:
   ```
   https://yourdomain.com/install
   ```
2. سيفحص المعالج توافق خادمك مع PHP و MySQL.
3. أدخل بيانات قاعدة البيانات التي أنشأتها في الخطوة (3).
4. أدخل اسم متجرك وعملتك، وبيانات حسابك كمدير عام (Super Admin).
5. اضغط **بدء التثبيت**. سيقوم النظام بإنشاء كافة الجداول الـ 25+ وحفظ ملف `.env` وإغلاق التثبيت لحماية متجرك.

---

### 6. الطريقة اليدوية البديلة (في حال أردت الاستيراد المباشر)
1. افتح **phpMyAdmin** في cPanel.
2. اختر قاعدة البيانات التي أنشأتها من القائمة اليسرى.
3. اضغط على تبويب **Import** (استيراد).
4. اختر ملف `database/schema.sql` واضغط **Go**.
5. قم بنسخ ملف `.env.example` إلى `.env` في المجلد الرئيسي وضع بيانات قاعدة البيانات به.

---

### 7. إعداد البريد الإلكتروني SMTP
1. في cPanel، افتح **Email Accounts** وأنشئ بريداً رسمياً (مثل `noreply@yourdomain.com` أو `orders@yourdomain.com`).
2. في لوحة تحكم المتجر Admin Panel ← انتقل إلى **Settings** (الإعدادات) ← **SMTP Email Settings**.
3. أدخل:
   - **SMTP Host**: `mail.yourdomain.com`
   - **Port**: `465` (مع تشفير SSL)
   - **Username**: `noreply@yourdomain.com`
   - **Password**: كلمة مرور البريد
4. اضغط حفظ. سيبدأ المتجر بإرسال فواتير الطلبات وإشعارات التجديد فوراً.

---

### 8. إعداد الـ Cron Jobs
لتحديث حالة الاشتراكات المنتهية وإرسال تنبيهات تلقائية للعملاء قبل انتهاء اشتراكاتهم:
1. في cPanel، ابحث عن **Cron Jobs** (المهام المجدولة).
2. اختر تكرار التشغيل: **Once Per Day (0 0 * * *)** (مرة كل يوم في منتصف الليل).
3. في حقل الأمر (Command)، اكتب:
   ```bash
   /usr/local/bin/php /home/YOUR_CPANEL_USER/public_html/api/cron.php >/dev/null 2>&1
   ```
   *(استبدل YOUR_CPANEL_USER باسم مستخدم cPanel الخاص بك)*.

---

### 9. لوحة تحكم الإدارة Admin Panel
- **الرابط المباشر**:
  ```
  https://yourdomain.com/admin
  ```
- **بيانات الدخول الافتراضية** (أو التي أنشأتها أثناء التثبيت):
  - **البريد الإلكتروني**: `admin@digitex.store`
  - **كلمة المرور الافتراضية**: `admin123`
*(يُرجى تغيير كلمة المرور فور الدخول الأول من صفحة الإعدادات أو حساب المدير)*.

---

### 10. النسخ الاحتياطي والصيانة
- **لقاعدة البيانات**: من cPanel ← **phpMyAdmin** ← اختر القاعدة ← **Export** ← نوع التصدير Quick ثم Go لتحميل نسخة احتياطية `.sql` كاملة.
- **للملفات**: من File Manager اضغط Compress لمجلد المتجر واحفظه كملف `.zip`.
- يمكنك أيضاً تصدير البيانات بنقرة واحدة من لوحة تحكم الإدارة في المتجر عبر تبويب **النسخ الاحتياطي وقاعدة البيانات**.
